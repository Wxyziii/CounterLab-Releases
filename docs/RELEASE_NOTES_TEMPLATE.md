## Update instructions

Existing CounterLab Alpha users:

1. Open CounterLab.
2. Use **Check for updates** / **Update now** when the update is offered.
3. Do not interrupt an active CS2 match to install a normal update.

New Alpha testers should download the installer from the Assets section of this release.

## Reporting problems

Use the repository's Bug Report issue template for normal defects. Do not post secrets in GitHub issues. Security vulnerabilities should be reported privately according to `SECURITY.md`.

## Checksums / signatures

Updater packages are validated by CounterLab using the Tauri updater signature configured in the application. Release assets should include the expected updater artifacts generated by the release build.
